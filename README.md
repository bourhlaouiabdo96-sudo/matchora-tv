# MATCHORA TV — مشروع مستقل

نسخة أولى مستقلة لموقع اشتراكات IPTV، وليست جزءًا من تطبيق المباريات أو الأخبار.
الصفحة الرئيسية باللغة الإنجليزية `/`؛ النسخ المحلية `/de` و`/es` و`/fr`.
الأسعار المتفق عليها بالدولار: شهر 14.99، ثلاثة أشهر 26.99، ستة أشهر 44.99، سنة 69.99.

## التشغيل

```bash
npm ci
npm run dev
```

افتح `http://localhost:3001`. للإنتاج: `npm run build` ثم `npm start`.
التحقق: `npm test` ثم `npm run test:e2e` بعد بناء المشروع.
التقنيات: Next.js وTypeScript وCSS مستقل، دون اتصالات بموقع الرياضة أو مفاتيحه.

## النشر المنفصل وربط الدومين

1. ارفع **هذا المجلد فقط** إلى مستودع GitHub جديد لموقع IPTV.
2. أنشئ **مشروع Vercel جديدًا**، واستورد مستودع المتجر. لا تستخدم مشروع الموقع الرياضي.
3. ضع `NEXT_PUBLIC_SITE_URL` على الدومين الجديد الكامل، مثل `https://your-new-domain.com`.
4. من Settings → Domains أضف الدومين الجديد ونسخة www، وطبّق سجلات DNS التي يعرضها Vercel.
   تبقى سجلات ودومين الموقع الرياضي كما هي.
5. بعد مراجعة الاسم والمحتوى، ضع `SITE_ALLOW_INDEXING=true` وأعد النشر لتفعيل الفهرسة وخريطة الموقع.

للمعاينة تبقى الفهرسة معطلة افتراضيًا؛ يستخدم المشروع عنوان Vercel الخاص به تلقائيًا إن توفر.
لا يحتاج مفاتيح API-Football أو Rexo أو Blob أو رمز CRON_SECRET، ولا تنسخها إليه.

## ما يعمل وما يحتاج إعدادًا لاحقًا

اختيار الباقة، الروابط، اللغات، الأسئلة الشائعة، صفحات الخصوصية والشروط والتواصل تعمل فعليًا.
الطلب حاليًا عبر WhatsApp أو البريد؛ لم تُربط بوابة دفع أو تفعيل اشتراك آلي.
يجب إكمال اسم التاجر القانوني وبياناته وشروط الخدمة والبيع، وتحديد مزايا الخدمة المتاحة فعلًا،
وطريقة الدفع والتفعيل والتجديد قبل تحصيل المدفوعات. لم تُضف أعداد قنوات أو تجربة مجانية أو
توافق أجهزة أو جودة بث غير مؤكدة. النصوص التنظيمية الحالية تصف مسار طلب المعلومات الموجود.

هذا المشروع لا يغيّر تطبيق الرياضة أو نشره. شراء الدومين وإنشاء مشروع Vercel وربط الدفع لم تُنفذ
من داخل هذه النسخة المحلية. يُتاح ملف ZIP للكود دون dependencies أو build outputs أو أسرار.
